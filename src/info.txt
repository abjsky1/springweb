HTTP(HyperText Transfer Protocol) : 컴퓨터 내부 or 컴퓨터 사이 데이터의 교환 방식을 정의하는 규칙 체계

    - 기본 요소 : 구문 , 의미 , 시간

    - 특징 : 단편화 , 재조립 , 캡슐화 , 연결제어 , 오류제어 , 흐름제어 , 다중화 , 주소지정

    - 계층별 프로토콜 종류 : 

        - 응용계층 : 응용계층 , 표현계층 , 세션계층

        - 전송계층 : 전송계층

        - 네트워크계층 : 네트워크계층

        - 링크계층 : 링크계층

        - 물리계층 : 물리계층
    
    - IP : 네트워크에서 장치를 구별하는 고유 주소

    - PORT : 프로세스 번호 ,  ex.Tomcat 서버가 사용하는 포트 번호 : 8080

    - 특징 : 무상태(상태 기억 X) , 상태 기억은 쿠키(Cookie)에 저장한다. 

    - 메소드 : 

        - 안전 : 호출해도 리소스가 변경되지 않음

        - 멱등 : 한 번 or 여러번 호출의 결과가 동일

        - 캐시 : 응답 결과 리소스를 임시 저장 가능


Servlet : HTTP 를 JAVA 에서 사용할 수 있게 구현한 웹 기술

Servlet 제공처 : Apache Tomcat , Spring Boot Web 에는 내장되어 있음.
